# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 3.x (latest) | ✅ Active |
| 2.x | ❌ End-of-life |
| 1.x | ❌ End-of-life |

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report security issues privately via **GitHub's built-in private vulnerability reporting**:
👉 https://github.com/Eng-MMustafa/nest-scramble/security/advisories/new

Or email the maintainer directly (find contact in the GitHub profile).

### What to include

- A clear description of the vulnerability
- Steps to reproduce or a proof-of-concept
- The affected version(s)
- Suggested fix if you have one

### Response timeline

| Action | Target |
|---|---|
| Initial acknowledgement | Within 72 hours |
| Severity assessment | Within 7 days |
| Patch release (if confirmed) | Within 30 days |

All confirmed vulnerabilities will be disclosed publicly after a fix is released, via a GitHub Security Advisory.
